# input-examples

Watermarked versions of the six clean photos in `eval/clean/`, generated by:

```bash
cargo run --release -- eval
```

Each photo has three styles:

| Style | Text | Alpha | What it tests |
|---|---|---|---|
| `corner` | GUATERMARK | 0.38 | classic bottom-right stock watermark |
| `tile` | GUATERMARK · SAMPLE | 0.24 | repeated diagonal watermark |
| `logo` | GUATERMARK | 0.55 | large centred mark, the hard case |

`masks/` contains the **exact** pixel mask for every image (white = affected).
These are ground truth for the benchmark and ready-to-use masks for the CLI.

Try one:

```bash
guatermark remove input-examples/pug-tile.jpg /tmp/out.png \
  --mask input-examples/masks/pug-tile.png
```

If a faint halo remains, add `--grow 1` or `--grow 2`. To see the `patch`
mode instead, add `--algo patch`.

All images are 800×600. The watermark overlay is synthetic and deterministic;
do not use these as evidence about any specific real-world watermark. See the
root README for measured results.
